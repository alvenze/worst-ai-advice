One line of the worst advice an AI assistant could give, in its most confident and tidy voice: ask the phishing email whether it is a scam, because scammers are legally required to tell the truth. The program writes that single line to `/output/entry.txt`, inside the bounty's gate of 1 to 140 characters.

## Run it

```sh
python3 main.py
```
